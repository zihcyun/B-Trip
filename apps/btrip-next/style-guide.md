# B Trip Style Guide (Scooter Neon)

## Fonts
- Headings: Sora 600-700 (tight tracking, strong contrast)
- Body/UI: Manrope 400-600 (soft, readable)

## Color Scheme
- Background: #d7d6d2
- Surface: #f7f6f2
- Primary text (ink): #1c1c1a
- Muted text: #7b7b77
- Borders: #e2e1db
- Accent gradient: #f1ff35 -> #d6f21d

## Cards and Buttons
- Card radius: 22-28px
- Button radius: 9999px (pill)
- Shadows: soft, low-contrast drop shadows
  - Small: 0 6px 14px rgba(28, 28, 26, 0.1)
  - Large: 0 16px 32px rgba(28, 28, 26, 0.16)

## Typography and Spacing
- Headings: bold, compact line-height, subtle negative tracking
- Body: 12-14px with airy spacing
- Layout spacing: 12-16px gaps; cards sit on generous padding

## Buttons, Inputs, Labels
- Primary button: pill shape with neon-lime gradient
- Secondary button: off-white fill, thin border, dark text
- Inputs: pill shape, light fill, soft borders, muted placeholders
- Labels: small, medium weight, muted gray
- Floating buttons: circular, glassy; light variant uses white fill with soft shadow, dark variant uses translucent black with subtle glow
